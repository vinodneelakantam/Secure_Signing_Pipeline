What protects the port
  1. Secure firmware creates 32 random bytes.
  2. The host signs exactly those bytes.
  3. Boot ROM validates against pinned trust.
  4. Unlock applies to one debug session only.
The repository C stub is a protocol model. Production systems require silicon-backed debug authentication and fuse provisioning.
